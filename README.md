# 🛒 Blinkit Sales Dashboard | Power BI

## 📊 Project Overview

An interactive **Blinkit Sales Dashboard** developed using **Microsoft Power BI** to analyze sales performance, outlet performance, product categories, and customer ratings.

## 📌 Key KPIs

- 💰 **Total Sales:** $1.20M
- 📈 **Average Sales:** $141
- 📦 **No. of Items:** 8,523
- ⭐ **Average Rating:** 3.9

## 🔍 Dashboard Features

- Interactive filters for **Outlet Location Type, Outlet Size, and Item Type**
- Outlet Establishment analysis
- Sales analysis by Fat Content
- Sales by Item Type
- Outlet Size and Location analysis
- Outlet Type performance comparison
- KPI-based sales and performance analysis

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
